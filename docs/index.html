Universal local hook adapter

One handler. Every harness.

Hitch normalizes Codex, Pi, OMP, Hermes, and OpenCode hook events into one envelope, runs your local handlers, records the audit trail, and translates decisions back into each harness.

Why Hitch?

Agent hooks should be portable.

Every harness has its own event names, payloads, and response rules. Hitch gives tool authors a stable local contract instead of forcing guardrails, loggers, and policy scripts to chase every native hook format.

Normalize once

Source hook JSON becomes a Hitch event envelope with harness identity, source event type, normalized event type, and payload.

tool.requestedsession.started

Dispatch locally

Handlers are ordinary executables. They read one JSON object on stdin and return a handler result on stdout.

shellpythonnodego

Translate safely

Synchronous decisions are aggregated deterministically, persisted, then translated back to the native response shape the harness expects.

allowdenyinject_context

The contract

A small control plane for local agent events.

Hitch stays boring on purpose: JSON in, external commands out, SQLite records underneath, and harness-native responses at the edge.

01Hook

Codex, Pi, OMP, Hermes, or OpenCode emits native hook data.

02Adapter

The harness adapter posts async or sync events to Hitch.

03Envelope

Hitch maps payloads into the universal event schema.

04Handler

Configured commands inspect, log, block, or transform.

05Response

Decisions become native harness output and audit records.

For tool builders

Ship a reusable policy pack or observer without binding it to one agent CLI.

For teams

Keep local guardrails, audit logs, and replay workflows consistent as harnesses change.

Quick start

Install, serve, verify.

The source installer seeds Hitch config with hitch config init. hitch-client install installs managed Codex command hooks into ~/.codex/hooks.json, installs Hermes shell hooks into ~/.hermes/config.yaml, installs a Pi extension into ~/.pi/agent/extensions/hitch/index.ts, installs an OMP extension into ~/.omp/agent/extensions/hitch/index.ts, and installs an OpenCode plugin into ~/.config/opencode/plugins/hitch.ts.

curl -fsSL https://raw.githubusercontent.com/sagebynature/hitch/main/scripts/install.sh | sh
hitch serve --config ~/.config/hitch/config.toml
hitch status --json
hitch doctor --json
hitch-client install --only codex --dry-run --json
hitch-client install --only opencode --yes --json
