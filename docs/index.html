The problem

Every harness speaks a different lifecycle language.

Each agent CLI has its own event names, payloads, response rules, and lifecycle boundaries. Guardrails, observers, context injectors, and workflow hooks should not have to chase five native formats.

Native JSON preserved Normalized event taxonomy Harness-native responses at the edge

Hitch in action

01Harness

Codex, Hermes, Pi, OMP, or OpenCode emits lifecycle data.

02Envelope

Hitch maps it to a stable event while retaining the original payload.

03Handler

Configured commands inspect events and return decisions.

04Observe

Decisions, audit rows, and replayable history stay in one place.

Quick start

Local-first. Remote-ready.

Run Hitch as a local daemon for your own agents, or point hook shims at a shared Hitch service for team-wide lifecycle routing and observability.

curl -fsSL https://raw.githubusercontent.com/sagebynature/hitch/main/scripts/install.sh | sh
hitch serve --config ~/.config/hitch/config.toml
hitch status --json
hitch doctor --json
hitch-client install --only codex --dry-run --json
hitch-client install --only opencode --yes --json
